# habit-tracker

A local-first habit tracker. Your data never leaves the browser — it is persisted in IndexedDB via Dexie.

## Stack
- React 19 + TypeScript
- Vite build, Tailwind CSS v4
- React Router v7
- Dexie (IndexedDB) for offline persistence
- date-fns for streak / date logic
- Design tokens compiled at build time

## Run
```bash
npm install
npm run dev
```
